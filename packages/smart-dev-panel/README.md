# dsh-smart-dev-panel

智能开发模式（agent preset `smart-dev`）的右侧栏伴侣面板：把一次开发任务的过程、消耗、工具、子代理、失败、技能与工作区状态做成**固定高度、可展开行详情**的可视化列表，并自动随 smart-dev 会话打开。

## 面板内容（固定高度行列表，全部行可下拉滚动，无「加载更多」）

- 列表区统一 **190px 固定高度**：所有行一次性渲染，超出部分在卡片内纵向滚动，卡片高度不随行数/展开变化；
- 行展开后给结构化详情：**任务**含完整命令、类型、状态、耗时、开始/结束时间、退出信息、Job ID、归属会话；**子代理**含模式、状态、输入/输出 token、步数、消息数、创建/结束时间、耗时、会话 ID、最近回报；**工具**含状态、耗时、轮次/步骤、完整参数、结果预览（失败为错误）、调用 ID。
- 同一行两张卡片**等高对齐**（网格 stretch），收起的卡片自动排到下方；
- 滚动条为 **2px 光束细线**：卡片主题色渐变 + 微发光，两端自然淡出；

- **Token 与上下文**：输入/输出/缓存读/缓存写/合计/上下文占用 + 上下文构成（系统提示 / 工具 schema / 消息）；
- **模型与缓存**：提供方、模型、推理档位、上下文窗口、可用工具数、MCP 服务、缓存命中率、首字延迟、解码速度；
- **工单计划**：`todos` 投影 + 完成进度，行详情显示完整内容与状态；
- **任务管理**：子代理拓扑（模式/状态/token/步数/最近回报）+ 后台任务（kind/标签/状态/耗时/退出详情）；
- **工具调用分布**：按工具名聚合调用次数、失败数、平均耗时；
- **最近工具调用**：最近调用及状态、参数标签、调用 ID；
- **失败与重试**：工具失败记录（错误内容、调用 ID）+ 模型重试次数与错误码；
- **步骤与耗时**：轮次、步骤、工具调用、模型/工具耗时；
- **技能使用**：本任务加载过的 skill、次数、最近时间；
- **工作区与变更**：git 分支、未提交项、工作目录、本任务写入/编辑过的文件（只读检测，git 不可用时自动降级）；
- **子代理消耗**：按 token 消耗排序的子代理排行（步数、消息数、最近回报）；
- **目标、审批与上下文**：goal/定时任务、等待确认的审批、上下文压缩次数与已裁剪 token。

## 头部

- 状态点、会话标题、全部展开/收起、刷新；
- 标签：预设、模型、事件序号、权限/沙箱/审批策略（危险权限标红）；
- 4 个渐变色 KPI 磁贴：上下文占用、Token 合计（含缓存命中）、子代理数、失败数；**点击磁贴会展开并滚动定位到对应分区，卡片高亮闪烁一次**（上下文/Token → Token 与上下文，子代理 → 任务管理，失败 → 失败与重试；失败为 0 时该磁贴不可点）；

## UI

- 头部身份标签改为**图标彩色胶囊**：模式（layers 图标，smart-dev 为绿色发光点）、模型（CPU）、数据序号（#）、权限（盾牌，危险权限标红、审批 ask 标黄）、工单数（有工单时出现），每个都有悬停提示；
- **空数据自动隐藏**：工具分布、失败与重试、技能使用、工作区、子代理消耗（少于 2 个）、目标审批、工单通道等分区在没有内容时整卡隐藏，不再出现整块空白；数据出现后自动恢复显示（常开/收起仍按设置）；
- 顶部操作按钮（设置 / 全部展开 / 全部收起 / 刷新）带**图标 + 主题色描边和淡色底**，悬停有轻微上浮；
- 设置浮窗里的上移/下移/恢复默认也用图标按钮；分区标题的 `?` 改为圆形帮助图标；
- 分区标题右侧计数胶囊使用该分区的主题色描边和淡色底；
- 每个分区顶部有专属色带（蓝=Token、紫=模型、靛=工单、琥珀=任务、青=工具、红=失败、绿=耗时、粉=技能、橙=工作区、青绿=目标审批）；
- 卡片渐变底色、悬停浮起、行悬停高亮、细滚动条、运行中脉冲点；上下文进度条为渐变+发光样式；
- **顶部「设置」按钮**打开面板设置：逐项切换「常开 / 收起」；分区顺序支持**拖拽行排序**（悬停显示六点拖拽手柄，拖动时目标位置有高亮线），也可用悬停出现的 ↑↓ 微调；一键恢复默认；设置保存在本机浏览器；
- **默认所有分区展开**；收起后卡片只保留标题行并缩到最小高度，不会再被同行卡片拉成空白大块；收起的分区自动排到面板下方，常开分区按配置顺序排在前面；
- 自适应两栏：内容宽度 ≥500px 两栏，更窄单栏；头部 KPI 磁贴自动换行，不溢出；
- 所有列表**只有纵向滚动**，长路径/长文本自动换行，不会出现横向滚动条。

## 入口与兜底

- 会话使用 `smart-dev` 预设时，右侧栏**自动打开**并显示面板（每会话一次，之后尊重手动关闭）；
- **自动开启团队协作**：检测到 `smart-dev` 会话时，通过 DSH 的 `agentTeams.setEnabled` 默认打开「启用智能体团队协作」；每会话每次启动只尝试一次，手动关闭后不会被反复打开；接口不可用时静默降级；
- 自动打开监听侧栏控制器的 `mounted`（屏幕会话）观察值，**不占用任何共享槽位**；
- 所有可选注册独立 try/catch：任一增强失败（如自动打开、git 检测）只跳过该功能，核心功能仍可用；
- Host 路由注册失败也只降级数据源，不影响其他插件。

## 实现

- Host（`index.js`）：`POST /api/dsh-smart-dev-panel/snapshot`，合并客户端投影（todos/token/上下文压力与构成/sessionStats/子代理目录）+ 会话日志折叠（标题/模式/工具/子代理/后台任务/权限/审批/重试/压缩/技能/文件/目标/定时），并按需只读读取 `git status`（2.5s 超时、8s 缓存、失败自动省略）；
- Client（`client.js`）：右侧栏 tab 类型 + 面板正文 + 自动打开；
- 数据只读，不写会话、不改其他插件。

## 注意

- 本包以目录链接方式安装到 profile；**不要删除本目录**，否则插件失效；
- 卸载：`plugin_manager` 的 `remove_bundle`，或 `dsh plugin --profile desktop remove dsh-smart-dev-panel`。
